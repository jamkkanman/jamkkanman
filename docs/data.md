# 내장 데이터

시연 위치: 서울 노원구 상계동, 노원역 남쪽 노해로75길의 "로그인 편의점 앞" 지상식 소화전(시설번호 노원-현장-001491, 37.6543883, 127.0589927)을 중심으로 반경 600m.
앱은 `app/src/main/assets/data/facilities.json` 하나만 읽고, 판정은 모두 기기 안에서 끝납니다.

| 유형 | 건수 | 데이터 | 기준일 | 이용 조건 |
|---|---|---|---|---|
| 소화전 | 103 (지상식 40, 지하식 63) | 서울 열린데이터광장 OA-21306 서울시 소방용수시설 현황 | 2026-09-10 | 공공누리 제1유형 |
| 버스정류소 | 24 | 서울 열린데이터광장 OA-15067 서울시 버스정류소 위치정보 | 2026-09-02 | 공공누리 제1유형 |
| 횡단보도 | 106 | 서울 열린데이터광장 OA-15554 서울시 교통안전시설물 횡단보도 정보(T-GIS). 좌표는 EPSG:5186에서 WGS84로 변환 | 2026-11-01 갱신 | 공공누리 제1유형 |
| 공영주차장 | 5 (모두 노상) | 공공데이터포털 15012896 전국주차장정보표준데이터 | 2026-04-14 | 공공데이터포털 이용정책 |

- 로그인, 인증키, 캡차 없이 각 포털의 내려받기 버튼과 같은 요청으로 받았습니다. 원본과 내려받기 기록(주소, 크기, SHA-256)은 저장소 밖 작업 폴더에 두었고, 저장소에는 가공 결과만 넣었습니다.
- 횡단보도 위치는 OA-22906(자치구 횡단보도 정보)의 위경도를 쓰지 않았습니다. 같은 관리번호를 비교하면 T-GIS 좌표를 바르게 변환한 위치보다 평균 남쪽으로 약 5m 밀려 있어, 5m와 10m를 가르는 판정에는 맞지 않았습니다.
- 횡단보도 폭과 길이는 이 지역 원자료에 값이 없어, 판정은 법정 10m에 기본 길이 8m의 절반(4m)을 더해 가장자리 기준에 가깝게 합니다.
- 공영주차장 5곳은 평일 09:00~19:00, 토요일 09:00~18:00(1곳은 평일만) 운영입니다. 운영시간 밖이면 안내 후보에서 빼므로, 19시 이후와 공휴일에는 "지금 운영 중인 공영주차장을 찾지 못했어요"라고 답합니다.

## 시연 지점 (`app/src/main/assets/data/demo_points.json`)

판정 거리(소화전 5m, 버스정류소 10m, 횡단보도 10m)로 보면 각 지점은 한 규칙에만 걸리도록 골랐습니다. 진행 방향은 북에서 시계 방향 각도입니다.

| 지점 | 좌표 | 기준 시설과 거리 | 다른 규칙 시설과의 거리 | 진행 방향 |
|---|---|---|---|---|
| 소화전 앞 정차 | 37.6544144, 127.0589838 | 지상식소화전 로그인 편의점 앞 3.0m | 정류소 80.0m, 횡단보도 43.1m | 74.7도 |
| 버스정류소 앞 하차 | 37.6553542, 127.0593269 | 노원역8번출구 정류소 7.0m | 소화전 56.7m, 횡단보도 33.1m | 73.6도 |
| 횡단보도 신호 대기 | 37.6537038, 127.0578261 | 노해로 횡단보도(보행등 있음) 5.0m | 소화전 30.6m, 정류소 38.0m | 254.0도 |

지점을 기준 시설에서 어느 쪽으로 옮길지는 OpenStreetMap 도로 중심선으로 정했습니다(시설 위치 자체는 공공데이터 좌표 그대로). 지도 데이터 © OpenStreetMap contributors, ODbL 1.0.

## 다시 만들기

```
python tools/build_dataset.py <수집한 demo_facilities.json> app/src/main/assets/data/facilities.json
./gradlew :core:demoScenarios :core:metrics
```

이 자료는 시연용입니다. 실제 단속 기준이나 현장 표지와 다를 수 있습니다.
