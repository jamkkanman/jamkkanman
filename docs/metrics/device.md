# 에뮬레이터 안에서 잰 값

Pleos Connect 에뮬레이터 2.1.0, 실차 신호 모드(Virtual Console과 adb로 입력)와 앱 지표 화면에서 기록한 로그를 요약했다.

## 반응 시간 (세우려는 신호 또는 응답에서 첫 음성까지)

| 묶음 | 횟수 | 중앙값 | 평균 | 최대 |
|---|---|---|---|---|
| 정차 안내 (첫 안내, 내리기 직전, 한 번 더) | 9 | 45 ms | 137 ms | 499 ms |
| 응답 뒤 문장 (주차장 안내, 확인) | 3 | 46 ms | 55 ms | 104 ms |

측정 지점은 앱이 신호 콜백을 받은 시각과 TextToSpeech EventListener.onStart 시각의 차이다. 차량 버스에서 앱까지의 지연은 포함하지 않는다.
